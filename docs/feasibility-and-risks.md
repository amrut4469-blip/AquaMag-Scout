# Feasibility & Risks

## Feasibility
- ✓ Technology – proven COTS sensors
- ✓ Integration – any ROV / AUV / lander
- ✓ Scalability – single pod → sensor array
- ✓ Cost – low-cost bill of materials
- ✓ Benefit – faster, cheaper screening

## Risks and Mitigation
| Risk | Mitigation |
|---|---|
| High pressure | Rated housing + potting |
| Corrosion | Titanium / POM + anode |
| Sensor drift | Auto-calibration + IMU |
| Vessel noise | Towfish + digital filter |
